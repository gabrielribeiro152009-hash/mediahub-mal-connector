# MediaHub — MyAnimeList connector (initial deployment)

This is an experimental, single-user connector and landing page. It is not yet connected to a ChatGPT plugin/MCP endpoint. Do not describe it as a production service.

## Deploy on Render

1. Create a new **public or private GitHub repository** and upload all files in this folder to its root.
2. In Render, choose **New → Blueprint** and select the repository. Render reads `render.yaml`.
3. After deployment, copy the service URL, e.g. `https://your-service.onrender.com`. Do not use the example URL literally.
4. In the Render service environment, set `BASE_URL` to that exact HTTPS URL. Add your `MAL_CLIENT_ID` and `MAL_CLIENT_SECRET` after creating the MAL app. Keep secrets in Render environment variables, never in GitHub.
5. In the MAL API application form, use:
   - App Redirect URL: `https://YOUR-SERVICE.onrender.com/auth/callback`
   - Homepage URL: `https://YOUR-SERVICE.onrender.com/`
   - App Logo URL: `https://YOUR-SERVICE.onrender.com/logo.svg`
   - Privacy Policy URL: `https://YOUR-SERVICE.onrender.com/privacy`
   - Terms of Use URL: `https://YOUR-SERVICE.onrender.com/terms`
6. Replace `YOUR-SERVICE.onrender.com` in the MAL form with your real Render domain. The redirect URL must match `BASE_URL + /auth/callback` exactly.
7. Save the MAL app, then set its Client ID and (for app type Web) Client Secret in Render's Environment settings. Save and redeploy.
8. Test `/health`, then the homepage, then Connect MyAnimeList. Only authorize your own account.

## Security notes

- `SESSION_SECRET` is generated by Render Blueprint. If setting manually, use a long random secret (at least 32 characters).
- The session cookie is HttpOnly, Secure, SameSite=Lax, and encrypted/authenticated with AES-256-GCM.
- This initial version stores tokens in an encrypted browser cookie; it is a personal prototype, not a reviewed production auth system. Never expose secrets in the repository or in chat.
- Do not add token logging. Review current MyAnimeList authorization documentation and API agreement before use.
- The list endpoint reads up to 20 pages of 1,000 items and returns a summary plus entries. No list-editing endpoints are implemented.
- Render free services may sleep when idle, so the first request can be slow.

## Routes

- `/` landing page
- `/privacy` privacy policy
- `/terms` terms of use
- `/logo.svg` public logo
- `/health` health/configuration check
- `/auth/mal` start OAuth
- `/auth/callback` OAuth callback
- `/api/me` current connected MAL user
- `/api/animelist` fetch list (optional `?status=completed`, `watching`, `on_hold`, `dropped`, `plan_to_watch`)
- `/auth/logout` disconnect

This version is not yet an MCP server and does not make the ChatGPT plugin live by itself.
